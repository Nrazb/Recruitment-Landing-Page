# Sekolah Karir Recruitment Landing Page

Landing page untuk menampilkan informasi peluang karier dan posisi pekerjaan yang tersedia. Pengguna dapat melihat daftar role dan menjelajahinya melalui tampilan carousel.

## 1. Teknologi yang Digunakan

- **PHP Native**: Mengatur struktur halaman dan menampilkan data role secara dinamis.
- **Tailwind CSS**: Membantu styling dan mengatur tampilan responsif.
- **CSS**: Mengatur desain tambahan seperti warna, glassmorphism, dan animasi.
- **JavaScript**: Mengatur interaksi carousel dan navigasi.
- **Google Fonts**: Menggunakan font untuk memperkuat tampilan visual.

## 2. Cara Menjalankan Project

**Persyaratan:**
- PHP 8.0 atau lebih baru.
- Web browser.
- Koneksi internet untuk memuat Tailwind CSS CDN dan Google Fonts.

**Menjalankan secara lokal:**

1. Download atau extract folder project.
2. Buka terminal pada direktori project.
3. Jalankan perintah:

   ```bash
   php -S localhost:8000
   ```

4. Buka browser dan akses:

   ```text
   http://localhost:8000
   ```

**Alternatif menggunakan Laragon:**

1. Pindahkan folder project ke direktori `www` Laragon.
2. Jalankan Apache melalui Laragon.
3. Buka project melalui browser.

## 3. Keputusan Utama

- Menggunakan **PHP Native** agar project sederhana dan tidak membutuhkan framework tambahan.
- Memilih kombinasi warna navy, putih, dan pink untuk memberikan kesan modern dan profesional.
- Menggunakan desain responsif agar tampilan tetap nyaman di desktop maupun perangkat mobile.
- Menampilkan daftar posisi pekerjaan menggunakan carousel horizontal agar halaman lebih ringkas dan pengguna dapat menggeser untuk melihat role lainnya.
- Memisahkan komponen halaman ke beberapa file PHP agar struktur kode lebih terorganisir dan mudah dikembangkan.
